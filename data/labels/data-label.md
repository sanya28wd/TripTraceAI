This table defines the standardized labels, categories, subcategories, and attributes used for lost-item identification.

| **Label ID** | **Category** | **Subcategory** | **Example** | **Allowed Attributes** | **Sensitive?** |
|:---:|:---:|:---:|:---|:---|:---:|
| `E01` | Electronics | Smartphone | iPhone, Samsung | Brand, color, model | No |
| `E02` | Electronics | Laptop | MacBook, Dell | Brand, color | Yes |
| `E03` | Electronics | Earbuds | AirPods | Brand, color | No |
| `E04` | Electronics | Tablet | iPad | Brand, color | No |
| `E05` | Electronics | Charger | Charger, power bank | Color, type | No |
| `E06` | Electronics | Camera | Digital camera, instant camera | Color, size, model | No |
| `B01` | Bags | Backpack | School/work backpack | Color, brand, size | No |
| `B02` | Bags | Handbag | Purse | Color, brand | No |
| `D01` | Documents | Passport | Passport | Country | Yes |
| `D02` | Documents | Card | ID card, credit card | Type | Yes |
| `D03` | Documents | Paper Documents | Receipt, printed ticket, non-ID paperwork | Size, description | No |
| `A01` | Accessories | Watch | Smartwatch, wristwatch | Brand, color | No |
| `A02` | Accessories | Keys | Car/house keys | Key type, keychain | Yes |
| `A03` | Accessories | Wallet | Cash wallet with cards | Color, brand | Yes |
| `A04` | Accessories | Clothing | Scarf, cap, glasses, umbrella | Type, color, brand | No |
| `A05` | Accessories | Jewellery | Earring, necklace, bracelet | Color, type | No |
| `M01` | Medicine | Medicinal Object | Pill bottle, inhaler, other medical device | — | Yes |
